# AllTag

Компактный редактор аудиотегов для Windows в духе Mp3tag: тёмный интерфейс
Material Design 3, панель редактирования и плотная таблица треков, пакетное
редактирование, конвертер «Имя файла ⇄ Тег» и интеграция в контекстное меню
проводника.

Всё приложение — **один переносимый `.exe`** без установки: движок тегов,
локальный HTTP-сервер, интерфейс и иконка упакованы внутрь файла.

![иконка](assets/icon.ico)

## Возможности

* **Форматы:** MP3 (ID3v1, ID3v2.2/2.3/2.4), FLAC, OGG Vorbis, Opus, Speex,
  M4A/AAC/ALAC (MP4), WMA/ASF, Monkey's Audio, WavPack, Musepack, WAV, AIFF.
  Чтение и запись тегов и встроенных обложек; аудиоданные никогда не
  перекодируются и не изменяются.
* **Пакетное редактирование:** выделите сколько угодно файлов — поля, значения
  которых различаются, помечаются как «смешанные» и остаются без изменений,
  пока вы в них не введёте новое значение.
* **Расширенные теги:** произвольные ключи (в том числе `TXXX`, `MOOD`, `ISRC`,
  ReplayGain), удаление отдельных полей, список встроенных изображений.
* **Конвертер имён:** маски `%artist% - %track% - %title%` в обе стороны с
  предпросмотром результата до записи и защитой от перезаписи существующих
  файлов.
* **Интеграция с проводником:** пункт «Открыть в AllTag» в контекстном меню
  папок и фона папок (HKCU, без прав администратора). Повторный запуск с путём
  в аргументах открывает папку в уже работающем окне.
* **Интерфейс:** акцентные цвета Material You (5 готовых + произвольный),
  сортировка по любому столбцу, поиск по таблице, виртуализированный список на
  десятки тысяч файлов, нативные горячие клавиши.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O` | Выбрать папку |
| `Ctrl+S` | Сохранить теги |
| `Ctrl+E` | Расширенные теги |
| `Ctrl+R` | Конвертер имён |
| `Ctrl+A` | Выделить всё |
| `Ctrl+F` | Поиск по таблице |
| `↑` `↓` | Навигация по списку |
| `F5` | Обновить список из папки |
| `Esc` | Сбросить поиск |

## Сборка

Нужен только Go 1.21+ — никаких C-библиотек, CGo и node.js.

```bash
# иконка и ресурсы (иконка + манифест DPI/UTF-8)
go run ./tools/iconbuild

# сборка
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -trimpath -ldflags "-H windowsgui -s -w" -o alltag.exe .
```

Проверка и тесты:

```bash
go vet ./...
go test ./...     # тесты движка и библиотеки (используют образцы в /opt/samples)
```

### Структура

| Путь | Назначение |
| --- | --- |
| `main.go`, `run_*.go` | точка входа, аргументы командной строки, единственный экземпляр |
| `internal/audiometa` | движок тегов (чистый Go, без зависимостей) |
| `internal/app` | модель библиотеки (`library.go`) и JSON API + SSE (`server.go`) |
| `internal/platform` | Win32, WebView2, проводник, реестр |
| `assets` | интерфейс: `index.html`, CSS, JS, иконка |
| `tools/iconbuild` | генератор `assets/icon.ico` и `rsrc_windows_amd64.syso` |

## Режимы отображения

По умолчанию интерфейс открывается во встроенном WebView2. Если WebView2
Runtime не найден (старые сборки Windows 10/11 без Edge WebView2), через
несколько секунд интерфейс открывается в отдельном окне Edge/Chrome в режиме
приложения, а нативное окно скрывается — функциональность при этом полная.
